## Arquitectura
Conjunto de componentes, protocolos y patrones de comunicación que permiten que una aplicación funcione a través de internet, que distribuye responsabilidades entre distintos sistemas.
## Modelo Cliente-Servidor
	Cliente
		* Solicita recursos
		* Renderiza la interfaz de usuario (Navegador o app movil)
	Servidor
		* Procesa solicitudes y aplica lógica
		* Administra datos y seguridad (API, base de datos, servicios)
