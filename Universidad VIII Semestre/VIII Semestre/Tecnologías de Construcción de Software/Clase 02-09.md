# Técnicas de Construcción de Software basada en Estados

### Stateful front end
almacena datos y recuerda las acciones, las entradas o el estado de la aplicación en la memoria del navegador mientras el usuario navega
* Redux
	Librería de JavaScript para gestionar el estado global de las aplicaciones de forma predecible centralizada


### Stateful backend
Es una configuración de servidor que recuerda los datos del usuario y el contexto de la sesión de una solicitud a la siguiente
