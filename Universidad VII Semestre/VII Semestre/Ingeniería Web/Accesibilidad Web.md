* Personas con algún tipo de discapacidad van a poder hacer uso de la web
* Es diseñar sitios Web que permitan que estas personas puedan percibiri, entender, navegar e interactuar con la web (Aportando a su vez contenido)
* Hay que tener en cuenta que existen millones de personas con discapacidad que no pueden utilizar la WEB
	* Web Accessibility initiative
* Tipos de validaciones para accesibilidad
	* WAI-A
	* WAI-AA
	* WAI-AAA
Componentes de accesibilidad:
1. Perceptible:
	1. Texto alternativo
2. Operativo
	1. Accesibilidad de teclado
3. Entendible
	1. On focus, tipo hover
4. Robusto
	1. Confiable
