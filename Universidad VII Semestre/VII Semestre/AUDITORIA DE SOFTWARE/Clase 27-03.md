# Auditoria
## Tipos de controles internos
* Preventivos.- Evitan que se materialice algo no deseado
* Detección.- Registran un evento no deseado después de ocurrido
* Reactivos.- El punto medio entre controles preventivos y de detección. No previene que ocurra un evento no deseado pero provee una manera sistemática de detectar que ha ocurrido y también señalan como se debe actuar frente a esta situación.

# Ley Sarbanes Oxley
creada en 2002 para cambiar el como se trabaja en empresas publicas y privadas con la idea de tener la información por mayor cantidad de tiempo y que pueda, es decir, un log de información

## Ejemplo: Control de cambios en el software
Un sistema que controla pagos y deudas y las personas beneficiarias
Si los cambios en el código del sistema no se aprueban y prueban adecuadamente, es posible que la lógica que ejecuta el código sea errónea. Esto podría generar una perdida de confianza en la integridad de los datos del sistema, lo que impediría saber con certeza quien ha pagado a la empresa y quién no. Entonces ¿Qué controles internos podrían mitigar este riesgo?
* No permita que los programadores tengan acceso lógico para actualizar el código de producción.
* Quienes tengan acceso lógico para actualizar el código de producción no podrán hacerlo sin pruebas y aprobación previa.

## Ejemplo: Backups y planes de recuperación
Si el sistema o sus datos se perdieran, la funcionalidad del sistema quedaría inaccesible, loque impediría
* Realizar copias de seguridad del sistema y sus datos periódicamente.
* Enviar las cintas de respaldo fuera de las instalaciones
* Documentar un plan de recuperación ante desastres.
